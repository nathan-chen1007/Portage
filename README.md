# Portage

Portage helps small Canadian exporters find their next market. Describe what you sell and it ranks international markets by friction (tariffs, regulations, customs and tax), all from sourced data. For the market you pick, it drafts the paperwork and the first message to a real importer, plus a voice note in the importer's language.

Built at AF Hacks: Growing Canada (Sept 26–27, 2026, Waterloo).
